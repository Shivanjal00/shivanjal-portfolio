How I work

I care about the whole journey of an app, from the first idea to the live release.

I started with Android in Java, moved to Kotlin, and then added React Native so a single codebase could ship to both stores. Knowing both sides lets me pick the right tool for each job: native when an app depends on the device, React Native when speed and reach matter more.

Much of my time goes into what users never see but always feel: smooth lists, audio that keeps playing in the background, live scores that arrive on time, and updates that never break what already works.
